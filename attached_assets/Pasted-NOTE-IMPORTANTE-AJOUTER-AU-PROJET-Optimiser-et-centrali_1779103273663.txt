1. MODULE GESTION DES CARTES / SERRURES HÔTEL
---------------------------------------------------

Ajouter un module complet de gestion des cartes RFID/NFC pour serrures d’hôtel, compatible avec systèmes type TTHotel / TTLock.

Fonctionnalités obligatoires :

- Encoder une carte d’accès chambre
- Associer carte + réservation + client
- Définir automatiquement :
  - date d’activation
  - heure d’activation
  - date d’expiration
  - heure d’expiration
- Désactivation automatique après checkout
- Réencodage carte perdue
- Historique complet des cartes générées
- Gestion multi-cartes par réservation
- Gestion multi-chambres
- Renouvellement d’accès
- Accès temporaire
- Activation immédiate
- Activation planifiée
- Vérification statut serrure
- Journal des événements serrure
- Compatibilité encodeurs USB RFID standards
- Préparer architecture compatible API TTHotel / TTLock

Centralisation obligatoire dans Super Admin :

- Nombre de cartes actives
- Cartes expirées
- Cartes désactivées
- Cartes perdues
- Statut des serrures
- Historique complet par hôtel
- Logs techniques encodeur
